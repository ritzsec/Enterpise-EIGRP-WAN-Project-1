# Verification & Troubleshooting Screenshots

This folder contains multiple other sub-folders that includes all the important screenshots captured during the implementation, testing, verification, and troubleshooting phases of the Enterprise EIGRP WAN Network Project.

Included verification scenarios:

* EIGRP Neighbor Formation
* Routing Table Analysis
* EIGRP Topology Tables
* VRRP Verification
* WAN Failover Testing
* Equal-Cost Load Balancing
* Unequal-Cost Load Balancing using Variance
* Traceroute Verification

These screenshots validate routing behavior, redundancy, failover, and enterprise WAN resiliency mechanisms.
