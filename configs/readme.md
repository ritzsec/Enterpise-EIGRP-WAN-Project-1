# Router Configuration Files

This folder contains the separated Cisco IOS configuration files used in the Enterprise EIGRP WAN Network Project.

The configurations are organized based on:

* Headquarters Routers
* Branch Routers
* ISP Transit Routers

Implemented configurations include:

* IP Addressing
* EIGRP Dynamic Routing
* VRRP Gateway Redundancy
* WAN Redundancy
* Variance-Based Load Balancing
* Failover Mechanisms

Each router configuration is provided individually for easier analysis, troubleshooting, and deployment reference.
